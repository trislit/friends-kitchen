# Notices

Friend's Kitchen uses FriendSDK v0.1.4 (Apache-2.0) for the runtime, canonical
Rare Friends Generations sprites, and procedural sound kit.

Character artwork: canonical Rare Friends Generations sprites. This game does
not replace that artwork.

The kitchen room, refrigerator, prep counter, serving counter, order computer, customer figures,
and ingredient markers are original CSS in `game/style.css`. The garden preset
is not used.

SDK source attribution and content hashes are recorded in the installed package
at `node_modules/@rarefriends/friendsdk/assets/provenance.json` and
`node_modules/@rarefriends/friendsdk/assets/sound-provenance.json`.

No third-party audio, fonts, or image packs are included.

React and React DOM retain their licenses in their installed packages.
